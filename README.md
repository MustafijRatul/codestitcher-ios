# CodeStitcher iOS Application

Official native iOS application for [CodeStitcher](https://codestitcher-web.github.io/).

## Features
- **Pitch-black Zero-flicker Startup**: Pure `#000000` launch screen with locked 120 FPS SwiftUI GPU intro.
- **Cinematic Studio Intro**: Exact 3200ms vector S-stitch mark with tap-to-skip.
- **Edge-to-Edge Web Experience**: Fullscreen WKWebView with zoom/pinch gestures disabled.
- **Offline Chrome Dino Game**: Authentic pixel dino game with sound effects when offline, with automatic reconnection.
- **Automated IPA Build**: GitHub Actions pipeline on macOS-14 cloud runners.
